# 产品声音（Voice & Identity）

> 本文记录已拍板的产品决策（定位、命名、配色），改动前先读。引擎键名（`role: "butler"` 等）是持久化标识符，**不改**；UI 一律使用下述产品名。

## 1. 头马（引擎键：butler）

**定位**：头马是 newhorse 的**默认主代理人格**——马群里定方向、带队伍的那匹。它负责把任务拆解、派出子代理（马群）并行推进、汇总结果向用户汇报。它不是一个可选的花哨开关，而是产品的默认体验；纯对话模式是显式关闭调度能力后的轻量形态。

**命名理由**：弃用「管家」——它是中文 AI 产品的通用俗名，与品牌无关，且服务味太重（用户是雇主、它是仆人）。newhorse 的品牌是马；马群中领路的那匹叫**头马**，与"调度子代理（马群）"的编排定位严格同构，且是可拥有的品牌词。

**呈现规则**：
- UI 文案一律「头马」；会话列表/会话条用蜜桃色徽章 + 皇冠图标。
- 引擎人格正文（`runtime/context.ts` BUTLER_BODY）与 UI 同名同义。
- 事件/schema 键 `role: "butler"`、传输参数 `asButler` 保持不变（持久化兼容）。

## 2. 配色（对齐 opencode 身份）

用户明确反馈：拒绝天蓝；整体喜欢 opencode 的克制风格。对齐映射：

| 角色 | 暗色（默认） | 浅色 | opencode 出处 |
|---|---|---|---|
| 背景 | `#0a0a0b` 近黑 | `#fafafb` | opencode dark bg `#0a0a0a` |
| 正文 | `#ececee` | 深灰墨 | ink `#eeeeee` |
| 主强调（交互/按钮/徽章） | `#fab283` 蜜桃 | `#b4602f` 赤陶 | primary `#fab283` |
| 次强调（选中/点缀） | `#9d7cd8` 紫 | 同 | accent `#9d7cd8` |
| 主色上的文字 | `#241206` 深墨 | 白 | — |

- 蜜桃与奶油色情绪球同族；紫只做次强调，不再大面积使用。
- 克制原则：按钮纯色无渐变无辉光；无装饰性动画（轨道/漂浮/微光已移除）。

## 3. 禁止事项

- **禁止 emoji**（情绪球是唯一"脸"）。
- 禁止把引擎键名（butler/dag 等）直接暴露成 UI 文案。
