向本地文件系统写入文件。

用法：
- 如果提供的路径下已存在文件，此工具会覆盖它。覆盖已有文件前，请先用 `Read` 工具确认其当前内容，以免丢失原有代码。
- filePath 可以是绝对路径，也可以是相对路径；相对路径相对于当前工作目录解析（工作目录见系统环境信息中的 "Working directory"）。推荐使用绝对路径。
- 此工具用于创建新文件或整体重写整个文件；仅修改已有文件的局部内容时，改用 edit 工具。
- 始终优先编辑代码库中已有的文件。除非确实必要，否则绝不写新文件。
- 绝不要主动创建文档文件（*.md）或 README 文件。仅当用户明确要求时才创建文档文件。
- 仅当用户明确要求时才使用 emoji。未经要求，避免向文件中写入 emoji。
