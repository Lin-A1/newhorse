查询每日活动总结（Daily Summary），了解用户最近做了什么。

每日总结是应用在每天 23 点后自动生成的，把当天你在本机各 AI 工具
（newhorse work 会话、newhorse 陪伴会话、Claude Code、Codex）中的
会话内容汇总成一段简洁的中文总结，包含当天的进展、结论和成果。

何时调用：
- 用户问 "我昨天/最近做了什么"、"最近都在忙什么" 之类的问题时
- 想了解用户最近的工作和陪伴会话内容，以便延续之前的对话
- 需要主动关怀用户时，先查看最近的总结了解其状态和关注点

参数：
- limit：返回的总结条数，按日期倒序，默认 7，最多 30
- from / to：可选时间范围（Unix 毫秒时间戳），只返回在该时间段内生成的总结

示例：
- daily-summary                    # 最近 7 天的总结
- daily-summary { "limit": 14 }    # 最近 14 天的总结
- daily-summary { "from": <某天0点>, "to": <某天24点> }   # 只看某几天的总结

返回每条总结的日期和正文，按日期倒序排列。
