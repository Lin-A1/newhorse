- 快速的文件模式匹配工具，适用于任何规模的代码库
- 支持 glob 模式，如 "**/*.js" 或 "src/**/*.ts"
- 返回匹配文件的绝对路径
- 当你需要按名称/路径模式查找文件时，使用此工具；查找包含特定内容的文件时使用 grep 工具
- pattern 是相对于 path 参数的路径模式；path 未提供时，相对于当前工作目录（工作目录见系统环境信息中的 "Working directory"）解析
- 当你在进行可能需要多轮 glob 和 grep 的开放式搜索时，改用 Task 工具
- 你有能力在单次响应中调用多个工具。最好主动把可能有用的多个搜索作为一批来执行。
