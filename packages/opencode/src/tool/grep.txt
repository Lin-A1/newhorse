- 快速的内容搜索工具，适用于任何规模的代码库
- pattern 是正则表达式，用于匹配文件内容；不要传入 glob 模式（如 *.ts）或纯文件名
- 支持完整的正则语法（如 "log.*Error"、"function\s+\w+" 等）
- 通过 include 参数按文件名模式过滤文件（如 "*.js"、"*.{ts,tsx}"）
- 返回包含匹配行的文件路径和行号
- 当你需要查找包含特定内容的文件时，使用此工具；按文件名/路径查找文件时使用 glob 工具
- path 参数默认是当前工作目录（工作目录见系统环境信息中的 "Working directory"）；相对 path 也相对于工作目录解析
- 当你在进行可能需要多轮 glob 和 grep 的开放式搜索时，改用 Task 工具
