Store and retrieve long-term memory that survives across sessions.

Use action "save" only when the user explicitly asks you to remember something,
or confirms something you proposed. Use provenance "user_explicit" when the user
directly stated it, "user_confirmed" when they approved your suggestion, and
"model_inferred" when you inferred it yourself — inferred entries are stored as
proposals and must not be treated as established fact.

Use scope "user_global" only for durable personal preferences that should apply
in every workspace. Everything else stays scoped to the current workspace.

Never save credentials, tokens, payment details, government IDs, precise
locations, or health information. Such content is refused.

Actions:
- list: show stored and proposed memory
- save: store a new entry
- accept: promote a proposed entry to active
- reject: mark a proposed entry as rejected
- forget: permanently delete an entry
