存储并检索跨会话保留的长期记忆。

仅当用户明确要求你记住某件事，或你推断出值得提议的持久性信息时，
才使用 action "save"。所有由工具发起的保存都会作为不受信任的提议存储；
只有用户才能在记忆中心（Memory Center）接受或拒绝它们。

仅在需要适用于每个工作区的持久性个人偏好时，才使用 scope "user_global"。
其他一切内容都保持限定在当前工作区。

绝不保存凭据、令牌、支付信息、政府证件号码、精确位置或健康信息。
此类内容会被拒绝。

Actions:
- list: 显示当前 Profile 可见的最近 50 条记忆
- search: 查找与查询相关的记忆（query 为必填）。可通过可选的 kind 缩小结果范围。
  最多返回 10 条匹配。当你需要某个具体事实而非近期历史时，优先用 search 而不是 list
- save: 提议一条新条目供用户审阅。需要 content 和 kind
  （preference、fact、goal、event、relationship 或 summary）。当该 profile
  的记忆功能被禁用时会失败
- forget: 需要 id。永久删除当前 Profile 可见的一条条目
- consolidate: 无参数。收集所有活动的 fact、event 和 preference，
  然后指示你把它们蒸馏成一条简洁的 "summary" 记忆
  （用 kind=summary 保存），并归档每条来源记忆（用 ids 归档）。
  当相关记忆变得冗余、应合并到一起时使用
- archive: 需要 ids（数组）。把这些记忆降级为 "paused"，使它们
  不再出现在 list 和 search 中，但不会被删除。用于退役旧记忆，
  或你刚合并成 summary 的那些来源记忆
- clear: 永久删除某个 scope 内的所有记忆。target 默认为
  "workspace"；"user_global" 会清除跨工作区记忆；"relationship"
  清除关系记忆，且仅在个人工作区（Personal workspace）中可用。
  仅当用户明确要求清除已存储的记忆时使用
