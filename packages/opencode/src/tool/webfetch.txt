- 从指定 URL 抓取内容
- 以 URL 和可选的 format 作为输入
- 抓取 URL 内容，转换为请求的格式（默认 markdown）
- 以指定格式返回内容
- 当你需要检索和分析网页内容时，使用此工具

使用说明：
  - 重要：如果存在另一个提供更好网页抓取能力、更贴合任务或限制更少的工具，优先使用那个工具而不是这个。
  - URL 必须是格式完整、有效的 URL
  - HTTP URL 会自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具是只读的，不会修改任何文件
  - 如果内容非常大，结果可能会被摘要化
