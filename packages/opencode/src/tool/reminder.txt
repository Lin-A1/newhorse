Create and manage user-requested reminders that persist across sessions.

WHEN TO CALL: whenever the user explicitly asks to be reminded or nudged at a
future time (phrases like "remind me...", "set a reminder...", "nudge me at...",
"tell me to..."). Do NOT just agree verbally — actually call this tool with
action=create so the reminder is stored and will fire.

Actions:
- create: requires title, body, scheduleAt (Unix milliseconds), and timezone; optional recurrenceRule supports only FREQ=DAILY or FREQ=WEEKLY with INTERVAL=1..365, plus misfirePolicy catch_up_once or skip
- list: show reminders in the current workspace
- update: requires id and any fields to change; paused=true pauses future occurrences, paused=false resumes; clearRecurrence=true makes the reminder one-shot
- cancel: permanently cancels future delivery

Use type "reminder" for a reminder explicitly requested by the user. Use
"check_in" or "follow_up" only when the user has explicitly enabled proactive
messages. Never create reminders to pressure, guilt, alarm, or manipulate the
user into returning.
