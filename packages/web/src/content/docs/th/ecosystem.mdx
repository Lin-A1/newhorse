ชุดโครงการชุมชนที่สร้างขึ้นบน Newhorse

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Newhorse ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-newhorse](https://github.com/awesome-newhorse/awesome-newhorse) และ [newhorse.cafe](https://newhorse.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
